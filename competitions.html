WiCS Hackathon

  • I led backend development, designing a Node.js and PostgreSQL backend with REST APIs powering a geolocation system built on the Google Maps API to track and surface nearby performers.
  • I also built a conversational chatbot interface that let users ask natural-language questions like 'who's playing near me?' and receive results pulled directly from the geolocation data.
  • Competing against 50 teams selected from across the university, we won Best Hack.
  • The project strengthened my ability to design backend systems, write functional code under tight deadlines, and communicate technical tradeoffs clearly to judges.
